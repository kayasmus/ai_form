## Quick Start

Run with Docker (no setup needed):

```bash
docker run -p 8000:8000 kayasmus/ai-form-analyzer
```

Then open http://localhost:8000 in your browser.

**Docker Hub:** https://hub.docker.com/r/kayasmus/ai-form-analyzer
